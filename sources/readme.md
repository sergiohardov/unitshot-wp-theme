# UnitShot Front End

## 📌 Описание

**UnitShot Front End** — это репозиторий фронтенд-верстки, который может использоваться:

- как **самодостаточный статический проект**
- как **frontend-часть WordPress темы**

Проект построен таким образом, чтобы обеспечить гибкость разработки и возможность переиспользования в разных средах:

- Использование Twig для унификации фронта с backend (WordPress)
- Использование npm пакета json-server для построения api запоросов
- Четкое разделение:
    - компонентов
    - блоков
    - страниц
- Поддержка работы как:
    - standalone проекта
    - подключаемого модуля
    - Автоматизация сборки и деплоя через GitHub Actions

---

## 🌿 Ветки репозитория

Репозиторий разделен на три основные ветки:

- **`main`** — основная ветка разработки
- **`preview`** — содержит готовую статическую сборку для деплоя на сервер
- **`module`** — содержит сборку, предназначенную для подключения в качестве модуля в WordPress

---

## ⚙️ CI/CD (GitHub Actions)

### 📦 `.github/workflows/module.yml`

- Срабатывает при `push` в ветку `main`
- Выполняет сборку проекта
- Подготавливает файлы для использования как WordPress-модуля
- Пушит результат в ветку `module`

### 🌐 `.github/workflows/preview.yml`

- Срабатывает при `push` в ветку `main`
- Собирает статическую версию проекта
- Деплоит на сервер
- Пушит результат в ветку `preview`

---

## 📁 Структура проекта

- **.github/workflows**
    - **module.yml** - Собирает проект как модуль для WordPress, пушит результат в ветку `module`
    - **preview.yml** - Собирает проект для статического превью, деплоит на сервер, пушит в ветку `preview`
- **dist** - Папка с финальными файлами сборки.
- **src** - Рабочая папка
    - **fonts** - Шрифты проекта
    - **images** - Картинки и иконки
    - **scripts**
        - **components/*.js** - Скрипты для компонентов
        - **blocks/*.js** - Скрипты для блоков
        - **pages/*.js** - Скрипты для страниц
        - **main.js** - Главная точка входа скриптов
    - **styles**
        - **base**
            - **mixins.scss** - SCSS-миксины
            - **reset.scss** - Сброс стилей
            - **vars.scss** - CSS-переменные
            - **fonts.scss** - Подключение шрифтов
            - **global.scss** - Глобальные стили
        - **components/*.scss** - Стили компонентов
        - **blocks/*.scss** - Стили блоков
        - **pages/*.scss** - Стили страниц
        - **main.scss** - Главная точка входа стилей
    - **twig**
        - **components/*.twig** - Разметка компонентов
        - **layouts/*.twig** - Базовые шаблоны (layout-обёртки)
        - **blocks/*.twig** - Разметка блоков
        - **pages/*.twig** - Разметка страниц
- **json-server-db.json** - Файл пакета json-server для создания api скриптов

## 🚀 Команды

Запуск проекта в режиме разработки  
По умолчанию dev-сервер доступен по адресу: `http://localhost:5173/<название_страницы>`  
Где <название_страницы> — это имя файла из: `src/twig/pages/*.twig`  
Пример: `http://localhost:5173/home`

```bash
npm run dev
```

Сборка проекта (production)

```bash
npm run build
```

Запуск json-server

```bash
npm run json-server
```
